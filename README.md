📊 HR Analytics Dashboard using Power BI

📌 Project Overview

This project focuses on analyzing employee data to identify key factors affecting employee attrition and overall workforce performance. The dashboard was developed using Power BI to transform raw HR data into meaningful insights through interactive visualizations and key performance indicators (KPIs).

The goal of this project is to help HR departments understand employee trends, monitor attrition rates, and make data-driven decisions to improve employee retention and workforce management.

🎯 Objectives
Analyze employee attrition trends across different departments.
Identify factors influencing employee turnover.
Monitor workforce demographics such as age, gender, and education.
Track key HR metrics such as employee count and salary distribution.
Build an interactive dashboard for easy data exploration.


🛠️ Tools & Technologies Used
Power BI – Dashboard development and visualization
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – KPI calculations and measures
Microsoft Excel / HR Dataset – Data source
Data Visualization Techniques – Charts, slicers, and KPI cards

📈 Key Insights Generated

Some important insights derived from the dashboard include:

Certain departments showed higher attrition rates compared to others.
Employees with fewer years at the company had a higher tendency to leave.
Specific job roles experienced frequent turnover.
Salary distribution showed variation across departments.
Younger employees showed different attrition patterns compared to senior employees.

These insights can help organizations improve employee retention strategies.
