# HR--Analytics

Developed an interactive HR Analytics dashboard using Power BI to analyze employee data and monitor workforce trends.
Collected and processed HR employee dataset to study employee attrition, salary distribution, job roles, and department performance.
Performed data cleaning and transformation using Power Query, including handling missing values and formatting data for analysis.
Created DAX measures and calculated columns to compute key HR metrics such as Attrition Rate, Employee Count, Average Salary, and Average Age.
Designed multiple visualizations including bar charts, pie charts, line charts, and KPI cards to represent workforce insights clearly.
Implemented interactive slicers and filters to enable dynamic analysis based on department, gender, education field, and job role.
Built department-wise and job role-wise attrition analysis to identify high-risk employee segments.
Analyzed employee demographics such as age group, gender distribution, and years at company to understand workforce patterns.
Generated actionable insights that help organizations understand employee turnover and improve retention strategies.
Improved data visualization and dashboard usability by applying structured layouts, consistent formatting, and user-friendly navigation.
